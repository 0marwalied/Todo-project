# Todo Project

A simple todo app to keep track of your tasks. Sign in, and your todos are saved to your account and private to you.

**Live app:** [0marwalied.vercel.app](https://0marwalied.vercel.app/)

## Features

- Sign up and sign in with your account
- Add todos with a title and an optional description
- Edit, complete and delete your todos
- Light and dark mode

## Built with

Next.js, Clerk, Prisma, MongoDB, Tailwind CSS and shadcn/ui.
